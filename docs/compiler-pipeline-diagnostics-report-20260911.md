## 实施决策与限制

验证阶段在 large 缓存命中产生 1,036,814 次分配/重分配、45.195 MB 请求流量。`ConstantFactAnalysis`、`IndexCheckAnalysis`、`ContainerLayoutAnalysis` 每次传播都复制当前行，transfer 内又复制输入。候选改为只读输入和每种分析一个可复用输出行，保留稀疏逐 PC 状态、控制流合并、所有验证及资源上限。将用分配计数、阶段配对时间、普通编译时间和错误输入回归共同验收。

输入指纹和未归属开销仍大于类型检查本身，当前数据不支持先重写 lexer/parser 或立即引入跨会话 arena 缓存。后续应继续细分输入身份验证/收尾，并审查可复用的身份和目录能力；稳定读取、并发源文件变化检测与缓存代次不能削弱。未归属部分包含尚未覆盖的 Engine 编排，不能全部归为 IO 或分配器。

这些是带阶段计时的诊断结果，没有给出优化前后普通编译提速，也没有证明运行时后端性能变化。本轮编译源码夹具偏向多包、数组和循环，后续复杂结构体/接口/外部依赖工程可能有不同分布。

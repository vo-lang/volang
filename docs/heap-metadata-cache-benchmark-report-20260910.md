# 小块堆元数据复用实验 · 2026-09-10

对照双方包含相同的预算为 1 时大对象回收修复与源码定位修复。唯一源码差异是 `SpanHeap` 对脱离托管页的小块元数据作有界复用。保留与否还需要结合语言程序和跨后端验证。

所有配对的校验和、托管分配量、托管容量与 GC work 完全相同。所有诊断进程的 collector 析构后请求字节收支为零。宿主请求字节不包含系统分配器开销；保留量减去了托管页，且不包含栈上 Gc 结构中新增的 96 字节目录。单元测试约束全部 12 类缓存的请求存储与固定目录合计不超过 20 KiB/Island。

每个类别最多保留一份小块元数据；托管页仍立即回到空闲池，可用于大对象。GC 步骤中只转移所有权，复用时再清位图和计数，保留有界 GC 工作量。

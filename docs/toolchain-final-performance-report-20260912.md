## Core 修正的取舍

原先约 70% 的整数查询回退已大幅缓解。最终简单方案相对回退前 P8：map-hit-miss +2.24%、jit-map +6.25%、接口键 +1.16%；删除重插入 −92.09%，宽键 −25.49%，float32/float64 Map −74.05%/−94.11%。用户要求平衡复杂度和性能后，本轮停止追逐剩余几个百分点。

对更早的原始计划基线，最终模块复用核对仍有 jit-map +9.26% [+6.76, +11.32]、sieve +3.34% [+3.11, +3.55] 的代价。这些结果与上面的 P8 对照使用不同基线，分别保留；本轮明确接受取舍，不声明所有场景都提速。

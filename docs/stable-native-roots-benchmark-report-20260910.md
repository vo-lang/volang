## 保留决定

保留本实现。独立复测中，两种GC模式的大根集宿主返回p99仍降低80.7%–84.8%；每次观察的GC work分别由98,372降至24,626、由106,558降至32,812。原有DirtyFibers扫描仍覆盖globals；暂停回调内稳定证明使后续sweep分片跳过重复全局根遍历。回调之间继续完整执行既有dirty和物化协议。

首轮两项无主动GC对照的明显p99回退没有稳定复现，16对复测的区间均跨过零；这支持保留决定，同时保留对小幅变化的不确定性。第二轮的绝对p99与第一轮不同，两个独立实验分别报告，未混合样本。no_std VM及Wasm VM编译检查均通过。后续组合产品、Native AOT与完整目录基准继续绑定新的产物身份验收；本报告没有将专项通过等同于整个优化计划完成。

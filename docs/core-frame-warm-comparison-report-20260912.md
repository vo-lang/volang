# Core 三方案模块复用报告 · 2026-09-12

原宿主、八项弱帧缓存、生成代码单帧缓存，八程序各六组独立进程对照。每个进程复用已编译模块，在两个预热之后测量四个新的运行实例；六种版本顺序均衡，统计单位为进程均值。144个进程、864次guest执行全部正确，其中576次正式执行。Wasm编译和显式宿主GC位于计时外；运行时创建、实例化与程序执行仍计时。

两份缓存候选均保持私有，完整冷进程对照已经分别出现递归树约+9.07%和+43.86%的代价。模块复用结果作为额外证据保留；本轮保留现有Core帧路径，关闭这两份候选的采纳工作。更大范围的执行状态拆分按独立架构决策处理。

完整冷执行分别见[弱缓存61项](core-weak-frame-cold-report-20260912.md)与[生成代码61项](core-generated-frame-cold-report-20260912.md)。正确性、逐函数调用、累计分配及准入约束见[帧缓存实验记录](core-frame-cache-experiments-20260912.md)。所有计时均只描述帧缓存增量，不与其他优化百分比相加。

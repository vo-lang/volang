# Studio Workbench

This permanent pure-Volang dogfood application exercises the public project
workspace, Unicode document, official editor, command, graphics, navigation,
UIKit, and desktop-window packages without an application JavaScript graph.

Its executable workflow covers three editable files, dirty state, undo/redo,
save, command search, VM/JIT development targets, Wasm/Native AOT release
targets, build output, documentation, embedded preview, restorable split/tab
layout, an offline route, and shared multi-window state.

Run the deterministic VM/JIT interaction contract with:

```sh
./eng/run-studio-workbench-contracts.sh
```

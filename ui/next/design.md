## 当前候选设计

组件定义、实例状态、依赖关系、事件处理、树比较、副作用和 HTML 序列化使用同一份 Vo
实现。浏览器管理 DOM、焦点、原生输入暂存和提交；VM 适配负责消息与执行恢复。
这条路径已经实际运行。共享 Rust 内核的成本对照尚未执行，运行时位置还没有完成选型。

应用 API 暂用普通 Vo 组合函数。props 使用结构体/普通函数，内容可以通过 View 或内容
函数组合。标量状态保持类型；结构化状态采用显式快照更新。状态 key 和组件定义显式
命名，避免全局组件栈或处理函数表。未来编译辅助需要以这些用例的表达成本和诊断效果
为依据。尚未将实验 API 声明为稳定契约。

## 时序与所有权

1. 原生事件按每个 root 独立的递增序号进入有界队列。普通重渲染保留事件目标身份，
   调用存活目标的最新处理函数。重复序号与已卸载目标会被拒绝。
   浏览器通过 MessageChannel 的任务交付输入，等待完整原生传播与默认动作结束；
   微任务可能在监听器之间执行，实际 reset 回归已证明需要这一区分。队列关闭释放端口。
2. 同一输入批次的状态写入合并。Flush 只执行受影响组件；同批组件按挂载顺序处理，
   父级先于子级。动态读取会替换旧订阅。
3. Flush 返回一个有唯一 revision 的完整批次。渲染期间禁止状态写入；下一次事件
   分发/Flush 必须等待这批的准确确认。没有 DOM 差量的输入也有确认，以结束受控输入回写。
4. 浏览器先验证整个批次的引用、顺序、属性、事件和拓扑，再应用 DOM 操作。确认后
   Root.Commit 先执行待清理资源，再执行有效的新 setup。副作用引发的状态写入进入下一批。
5. Exchange 的非空请求提交并返回确认，空请求等待输入；关闭返回 EOF。没有 sleep 或
   周期扫描。副作用无需等待下一次用户输入才启动。
6. 卸载先使作用域失效，再清理资源。正常清理失败仍尝试其他清理；render 失败由最近的
   错误边界恢复，未捕获的 render 或 setup 失败终止该 root 并释放既有资源。主失败保留，
   失败展开中额外的 cleanup 错误暂未汇总诊断。

SSR 只 Flush 和 HTML，跳过 Commit，不启动浏览器副作用。客户端按标记验证同一结构、
复用节点并确认挂载。启动前输入从原生控件和早期事件队列恢复。接管后才启动副作用。
需要服务端和客户端共享确定的初始数据；查询结果已有受限快照，通用组件状态序列化与
mismatch 恢复还没有实现。

原生输入的临时内容与 guest 已处理的输入序号共同决定回写时机。较旧提交不会覆盖较新
原生 value/checked；组合输入期间保留原生编辑。Guest 拒绝的编辑在确认后恢复受控值。
移动节点范围时保留 DOM 对象，并恢复发生失焦的原输入控件及选区。

当前批次预检查能够在实际 DOM 修改前拒绝已覆盖的协议错误；它没有提供浏览器异常或
外部控件副作用的通用事务回滚。请求错误和控件错误已有结果回传。

`ErrorBoundary` 在渲染前保存边界直接子节点 ID 和当前差量位置。新节点先登记到所属
父节点，确保半途挂载的子树也能完整释放。捕获失败后丢弃该次未发布的差量、取消子树
任务、释放作用域，再移除旧子节点并生成 fallback；正常提交后执行 cleanup。不会为每次
更新复制整个树。独立 dirty 子组件也重建祖先边界的捕获顺序；fallback 失败由外层捕获。
重试创建新内容实例，旧错误对象的 Retry 无效。此版本明确只捕获 render/reconcile 失败，
处理函数、副作用、cleanup 和宿主异常继续使用各自错误路径。现在已保存组件名称、key
及定义文件/行号；错误展开时按实际所有者链生成快照，普通渲染不分配诊断列表。边界的
`Components()` 返回独立副本；未捕获的 `RenderFailure` 保留原始 Value 和同一份诊断。
定义位置通过标准 `runtime.Caller` 获取，不宣称它是具体 panic 语句的位置。

## 本轮补齐的架构切片

派生计算与组件共用依赖观察者。派生值按需求值，多次读取复用缓存；菱形依赖在同次
渲染中读取一致结果，循环计算有诊断。每次所属组件重新声明时更新计算闭包并使缓存
失效，以保证普通 props 不过期。这一取舍需要在下一步对照中测量，尚未实现编译辅助更新。

结构化状态通过值快照与显式集合复制更新。上下文沿组件祖先查找；嵌套 provider 可以
先读取外层值再提供覆盖。两者都在实际组合示例使用。无泛型带来的 `any` 边界仍由类型化
业务封装承担；完整的编译期上下文和属性诊断尚未提供。

请求在提交后启动，使用 root 内永不复用的任务 ID。替换、取消、作用域卸载先移除结果
处理入口，再发送取消；浏览器用 AbortController 停止 I/O。即使提供方忽略 abort，返回值
也会在宿主和 guest 两层被丢弃。状态只经同一事件队列写入。标准 Resource 提供
pending/value/error 与显式重试；HTTP 和计时器已有可运行接口。任意 Vo worker、并发组合、
缓存去重和完整后台调度仍待实施。`Request.WithTimeout` 在提交后的宿主开始时间建立
计时器；超时使任务退出、发送本地错误并 abort，迟到结果无效。成功、取消与关闭都清理
计时器；改变超时会替换请求，Reload 创建新期限。测试覆盖可控时钟和真实 HTTP 重试。

HTML/SVG 命名空间由最终拓扑推导，组件和片段保持所在上下文；`foreignObject` 内使用
HTML，跨命名空间的现存节点移动在提交前拒绝。SSR 输出和接管已覆盖 SVG 图形、渐变、
标题和嵌入 HTML。textarea 使用 value 绑定输出原始内容，补偿 HTML 开头换行规则，
提前编辑与离线克隆控件的原生默认值比较，避免将数字输入净化或 select 默认选择误认成
用户输入；控制标记区分受控和原生内容。select 子选项变化后重新落实受控值，SSR 从
父 select 的值推导 option 选择。原生 reset 后按 guest 状态恢复受控字段，未绑定字段保留
浏览器的重置行为。非空 file 值在 DOM 修改前拒绝，SSR 也有对应诊断。

外部控件拥有一个独占 DOM 子树，框架拒绝往该子树插入自己的子节点。宿主在 DOM 批次
提交阶段执行 mount/update，并将交互排入事件队列；卸载先撤销所有被移除实例的事件入口，
再 abort 和 dispose。真实 [uPlot 1.6.32](https://github.com/leeoniya/uPlot) 通过类型化 Vo 包接入，
实现数据更新、游标回传、ResizeObserver 和清理。SSR 保留占位，接管后只创建一次。
扩展提供方须负责部分初始化失败时的外部资源释放。

线协议现为实验 v18；当前包含任务超时、事件选项/payload、按键及修饰键过滤、完整多选值、焦点/滚动/模态/浮层/Portal/原生默认值指令、滚动容器观察、指针进入/离开及 pointerType 和初始数据握手。
从同一 schema 生成两侧编解码器，使用固定宽度整数、操作编号、长度前缀字符串和数组；
编码/解码共同限制帧大小、数组数量和整数范围，拒绝截断、尾随数据和错误版本。
新旧产物须一起重新生成及构建；仅适用于未发布的新路径。任务和用户 effect 使用不同的内部 key 类型空间，避免
业务命名与框架内部生命周期意外冲突。默认旧 UI、稳定 API 与发布声明没有切换。

`OnWith` 允许同一节点分别声明捕获和冒泡处理函数。默认动作与传播控制在浏览器原生
监听器内同步执行，guest 收到有序事件和键盘修饰键/组合状态等快照。选项变化会更新
对应阶段的监听，卸载按相同 capture 参数移除；Passive 与 PreventDefault 组合在生成
批次前拒绝，宿主也会预检查。`On("submit")` 保持托管提交的默认动作抑制，其他普通
监听不改变默认动作；`OnWith` 明确替换默认设置。真实浏览器覆盖动态选项和快捷键。

`Ref` 归属于 Scope，可传给同一 root 的子组件，提供受管理的 Focus 操作。引用可以在
一次重建中从旧节点转移到新节点，提交前检查最终绑定的唯一性。Focus 在同批树完成后
解析，已移除/未绑定目标不发送指令；宿主在原生值回写后执行。重复绑定属于提交前的
契约错误，会终止 root；跨 root 绑定不会清除原 root 的引用。SSR 跳过 focus effect。
显式 Focus 允许原生滚动将目标带入视口；换序后的焦点恢复保留滚动。
DOM 测量、显式滚动、选区控制和通用 Portal 仍待补齐。

`Subscribe` 与一次性请求共享 Scope、递增 ID、取消和超时。成功值可连续交付，错误终止
订阅；`Watch` 按请求管理 effect，只刷新变化后的回调，避免旧 props 或重复安装。宿主
提供方通过 AbortSignal 释放监听。原生和两个 Web 后端覆盖多值、替换、错误、条件删除
与关闭；Node 另验证部分安装失败及终止后的迟到消息。

`navigation.Use` 通过受管理订阅读取路径、查询与片段。Link 保留普通 href；只有无修饰键
的同源 HTTP 链接才被导航服务接管，新标签、下载、外链等保留原生行为。push/replace
通知当前窗口的活跃 root，popstate/hashchange 同步历史变化；root 释放时移除监听。
同页锚点交给浏览器处理滚动与焦点。Studio 的后续导航已更新主区域焦点和文档标题；
`navigation.NewRoutes` 增加纯 Vo 嵌套布局、默认子页、动态参数和末尾 rest 匹配。
构建时复制路由表并检查 ID/模式歧义；匹配采用静态段、参数段、rest 的明确优先级。
路径逐段解码，编码斜线保留在一个参数里。布局及叶子状态按路由定义身份保留，参数
变化更新 props，离开分支时释放任务/效果。Studio 的两层布局与动态文档章节已实际接入；
章节切换保留文档搜索，离开文档释放局部状态，外层 shell 持续保留。原生和三引擎、
两个 Web 后端的生命周期、历史导航、深链接接管及启动前输入回归已通过。
可选 `navigation.Restore` 让一个作用域拥有窗口视口；新 URL 的视图提交后才恢复位置/焦点，
同时等待原生历史事件的默认动作结束。恢复通知携带观察者和导航代次，过时/重复/取消的
通知不会移动当前页面。历史返回支持短暂跟随异步布局增长，用户操作、新导航或卸载
立即结束跟随。原生锚点保留浏览器语义，替换 query 可显式保留视口。三种引擎均已验证
原生历史边界及两个后端的 Studio 往返位置/焦点；SSR 启动前输入仍保留。
窗口外的滚动容器、完整刷新后的历史、延迟加载与虚拟列表恢复仍需扩展。
详见 [navigation API](navigation/README.md)。

## 2026-09-14：类型化 HTTP 与原生 JSON

`web.HTTP` 将方法、文本正文、凭据策略和请求头编码为确定的请求身份；
`DecodeHTTP` 保留可读取的状态码、响应头、最终地址与正文。普通 4xx/5xx 由应用解码，
422 可直接返回表单字段错误。服务端 `JSON(status, value)` 复用已有原生入口与响应头，
跳过 HTML/接管模板。请求时协议升级为 3，增加 PUT/PATCH/DELETE/OPTIONS；DOM wire 保持 17。
浏览器适配只执行 Fetch，应用的解码、重试、缓存失效和字段规则继续留在 Vo。

HTTP 与 FetchText 共用有界读取器，按实际解压正文限制 2 MiB，并在超限、取消、超时
或卸载时释放读取器。请求正文限制 1 MiB，JSON 最坏转义仍可进入现有 UI 帧。
原先两个约 9 MiB 的合法输入同批到达会因合并帧超限而终止 root；队列现持有独立编码
数据，按 16 MiB 帧分批并保留 FIFO，按 4096 事件和 64 MiB 队列同时限制积压。
入队后的调用方修改不再改变已排队数据；原生事件分发完成后再唤醒 guest 的时序保留。

原生 VM/JIT 与工具层 55 项检查通过；新增大容量 JSON 用例使聚合 AOT 契约测试的执行
预算由 1 亿调整为 5 亿，应用运行预算保持现值。真实部署表单在三浏览器 × VM

## 同一 root 内的 Portal 挂载

`View.Portal(targetRef)` 将普通 HTML 元素挂载到同一 root 的另一个可容纳子节点的
HTML 元素。原组件树继续拥有状态、上下文、任务和清理；DOM 位置决定原生事件路径、
样式继承、表单关联与可访问顺序。框架不复制祖先的样式和处理函数。需要固定原生
表单归属时使用显式 `form` 属性；模态、焦点范围和定位继续组合已有 Dialog/Popover。

来源位置保留一个由宿主管理的注释节点。普通插入和换序操作作用于该来源位置；目标
内的 Portal 按创建顺序排在普通子节点后。目标缺失、解除 Portal 声明会将原元素放回
来源，节点、输入与组件身份保持。删除逻辑来源时先取消所拥有的 Widget，再清理已经
移动到别处的 DOM；删除目标时先安置仍存活的来源。位置不变的提交不移动 DOM。

实验 wire 升为 v18，增加目标节点 ID 指令和共享的 64 个 Portal 上限。Vo 在引用解析
完成后检查归属与挂载图，浏览器再对完整批次检查最终物理父链，拒绝自身、逻辑后代
及相互挂载形成的循环。目标可以在同批次中后创建；任一无效关系在 DOM 写入前失败。
未声明 Portal 的普通更新跳过挂载图检查，不增加全树扫描。

SSR 继续生成来源位置的语义 HTML，浏览器接管原节点和提前输入后再挂载到目标。
首次激活可能调整布局，因此服务端的来源内容本身应当可读。当前 API 限定同一 root，
不接受任意 selector、跨 root 或 document-body 句柄。实现和完整边界见
[Portal 使用说明](portal.md)；真实系统输入法与辅助技术验收仍独立执行。

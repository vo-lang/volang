## Normative reference

The files in [`spec/`](spec/) define current language, module, runtime, and
bytecode behavior. Guides optimize for learning and everyday use. When a guide
and a specification appear to disagree, treat the specification and executable
tests as authoritative and report the guide drift.

Design histories live under `dev-notes/`; superseded material lives under
`outdated/`. Neither directory is user-facing product documentation.

## Updating Studio documentation

After editing a catalog page, regenerate the checked-in Studio package:

```sh
cargo run -q -p vo-dev --locked -- generate studio-docs --write
```

Validate source structure, catalog coverage, provenance, and generated bytes:

```sh
cargo run -q -p vo-dev --locked -- lint docs
```
